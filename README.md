# BSEP Vocabulary Trainer

Aplicación React + Vite preparada para Vercel.

## Uso

```bash
npm install
npm run dev
```

Para añadir palabras, agrega nuevos objetos al arreglo de `src/bsep.js`. El progreso se guarda automáticamente en `localStorage`.

## PWA

La aplicación incluye manifest, service worker, iconos instalables y caché offline. Después de publicarla por HTTPS en Vercel, puede instalarse desde el navegador como una aplicación independiente.

## Historia de Destiny

Incluye una adaptación educativa en inglés, organizada cronológicamente en 13 capítulos. Las palabras BSEP aparecen claramente resaltadas con su sinónimo, abren su ficha al tocarlas y cada capítulo termina con una pregunta de comprensión.
